# ISP Malaysia Member Guide

A static, mobile-first Progressive Web App that directs visitors to the official ISP Malaysia pages. It does not collect data and does not provide a member login.

## Publish with GitHub Pages

Upload this folder's contents to the repository root. In GitHub, set Pages to deploy from the default branch and the repository root (`/`). The public site will then be available at `https://<account>.github.io/<repository>/`.

Content links were checked against https://isp.org.my/v4/ on 17 October 2026.
