## Data and security

All records exist only in JavaScript memory and clear on refresh or sign-out. No backend, analytics, external scripts, real payment, application, enrolment or enquiry submission. No CV upload. The supplied client-side demo password is public prototype access, not secure authentication. Never use it to protect real member records. External ISP and Mentimeter links leave this demo.
