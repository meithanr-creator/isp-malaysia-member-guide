## Owned terminal cleanup and proof

The private proof runner adds only a Job-specific cleanup barrier. Before deleting attachments/objects, it transactionally sets cancellation plus a journal-owned fence; no-dispatch gets a tombstone that invalidates a stale initial CAS. It observes/cancels the exact Workflow and verifies the released revision reaches terminal. Then it refreshes the marker to recover an early worker ID, resolves exact validated operation/execution names, and verifies immutable image plus all four dispatch values before observing/cancelling only that Job. Operation, Workflow and worker execution receipts must agree. A missing receipt is never proof no Job launched. Only a successful explicit pre-POST exit or exact Job terminal completion permits final deletion; the final transaction rechecks the same fence/dispatch ID. UNKNOWN retains metadata and blocks another attempt.
